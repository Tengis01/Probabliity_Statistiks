developer: The name of the studio or individual who created the game.

publisher: The entity responsible for marketing and distributing the game on Steam.

tags: A list of user-defined descriptors (e.g., "Indie", "Simulation", "Open World").

genres: High-level categories assigned by Steam (e.g., "Action", "RPG").

languages: A list of supported interface, audio, and subtitle languages.

review_summary: A string describing the general sentiment of user reviews (e.g., "Very Positive").

review_count: The total number of user reviews submitted.

review_percent: The percentage of total reviews that are positive.

windows_requirements: A nested object containing minimum and recommended hardware specs for Windows.

linux_requirements: A nested object containing hardware specs for Linux-based systems.
